How it works

A hosted booking API that lets AI agents search real-time availability, hold a slot, and confirm a deposit-backed appointment with a home-service provider — over REST or MCP. Priced per location, with a small success fee on top.

01

Built for how agents book, not how humans browse

search_service_slots, hold_appointment_slot, and confirm_deposit_booking are exposed as both REST endpoints and native MCP tools, so an agent can complete a booking without a human clicking through a calendar.

02

Never double-books, never double-charges

Each booking runs as a resumable, idempotent saga — the deposit is authorized, the slot is re-verified against the provider's live calendar, and only then captured. A failure at any step voids the charge and releases the slot automatically.

03

Disclosed, bounded sponsored placement

A provider on the Enterprise plan can pay for placement, but it only breaks ties among results within 30 minutes of the soonest slot — and every such result is labeled sponsored, so urgency is never sacrificed for revenue.
